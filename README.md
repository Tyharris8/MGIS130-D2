# MGIS130-D2
   GPA tracker

## Data Layer-What information goes in
    Will collect data directly from students
    Course names
    Credit hours
    Letter grades(actual or hypothetical for each course)
  
### Processing layer-What will we do with it
    Convert letter grades into numerical grade points
    Multiply grade points by course credit hours
    add total grade points and divide by total credit hours
    Recalculates grades when students update them 
    Calculate predicted semester GPA using hypothetical grades

#### Presentation-How should it look
    Clean simple design that's easy to navigate
    A form for entering courses, credits, and grades
    An add course button to enter additional classes
    A calculate GPA button
    A clearly displayed semester GPA
    An option to enter hypothetical grades and view predicted GPA
    Layout works across devices(computers, smartphones, etc).
